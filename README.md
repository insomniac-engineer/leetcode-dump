# leetcode-dump

Raw [LeetHub](https://github.com/QasimWani/LeetHub) dump of accepted LeetCode submissions.

This repo is **not** a study handbook. Curated notes, patterns, and cleaned-up solutions live in **[dsa-notes](https://github.com/insomniac-engineer/dsa-notes)**.

## Workflow

1. Point LeetHub at **this** repository (not `dsa-notes`).
2. Solve on LeetCode as usual. After an accepted submission, LeetHub pushes the raw files here.
3. When a problem is worth keeping, copy it into `dsa-notes/problems/<id>-<slug>/` and add `pattern:` metadata there.

Do not edit this repo by hand. Treat it as an append-only inbox.
